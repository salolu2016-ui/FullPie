# 🥧 FullPie

Aplicación móvil desarrollada con **React Native** y **Expo** para la visualización de un catálogo de pies artesanales. El proyecto implementa navegación, diseño responsivo y adaptación a diferentes orientaciones de pantalla como parte del **Diplomado en Diseño y Programación de Apps**.

## 📱 Características

- Pantalla de bienvenida.
- Catálogo de pies artesanales.
- Carrusel horizontal de productos.
- Pantalla de detalle y compra.
- Diseño responsivo para teléfonos y tabletas.
- Adaptación a orientación vertical y horizontal.
- Navegación mediante Bottom Tabs.
- Encabezado con efecto Parallax.

## 🛠 Tecnologías utilizadas

- React Native
- Expo
- JavaScript (ES6+)
- React Navigation
- Expo Vector Icons

## 🚀 Instalación

### Clonar el repositorio

```bash
git clone https://github.com/salolu2016-ui/FullPie.git
```

### Ingresar al proyecto

```bash
cd FullPie
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar la aplicación

```bash
npx expo start
```

## 📱 Funcionalidades

### 🏠 Inicio

Presenta la información de FullPie, los sabores disponibles y un mensaje de bienvenida.

### 🥧 Menú de Pies

Permite navegar mediante un carrusel horizontal para visualizar cada producto con:

- Imagen
- Nombre
- Precio
- Ingredientes
- Descripción
- Botón de compra

### 🛒 Compra

Muestra el resumen del producto seleccionado y permite iniciar el proceso de compra.

## 🎨 Diseño Responsivo

La aplicación implementa una interfaz adaptable utilizando:

- Flexbox
- ScrollView
- useWindowDimensions
- Componentes reutilizables
- Adaptación para orientación vertical y horizontal
